## ⚡ Executive Engineering Summary

Senior Embedded Systems Engineer with **6.7+ years of production experience** delivering deterministic, safety-critical firmware across automotive diagnostics, industrial automation, and edge telemetry domains.

* **Architecture & Firmwares:** Specialized in register-level **Embedded C (C99/C11)** on **ARM Cortex-M4 (STM32F446RE @ 180 MHz)** and **Microchip PIC18**, deterministic non-blocking multi-rate superloops, zero-dynamic-heap architectures, and FreeRTOS multi-threading.
* **Automotive In-Vehicle Networking:** Comprehensive implementation of **CAN 2.0B / CAN-FD**, **ISO 14229-1 (UDS)** diagnostic servers, **ISO 15765-2 (DoCAN)** transport layer segmentation, and hardware bxCAN filtering.
* **Signal Processing & Systems:** Edge DSP algorithms (**1024-Point Real FFT on Cortex-M4 hardware FPU**), dual-slot fail-safe **In-Application Programming (IAP) Bootloaders**, and **Python-based automated Hardware-in-the-Loop (HIL) test suites (pytest)**.
* **Industrial Deployment Track Record:** Proven track record spanning 4.7+ YOE in production firmware design and 2.0 YOE in hardware bring-up, PCB fault isolation, and bench verification using oscilloscopes and logic analyzers.

## 🏆 Featured Production Repositories (STM32 NUCLEO-F446RE & Automotive)

### 🚗 1. [stm32-automotive-uds-isotp-node](https://github.com/sherifred-singh/stm32-automotive-uds-isotp-node)
> **Production ISO 14229-1 (UDS) Server & ISO 15765-2 (DoCAN) Transport Layer on STM32F446RE (ARM Cortex-M4 @ 180 MHz)**
* **Network & Transport Layer:** Complete ISO 15765-2 DoCAN stack handling Single Frame, First Frame, Flow Control (with `BS` and `STmin`), and Consecutive Frames with strict timing supervisors (`N_Bs`, `N_Cr`).
* **Diagnostic Services:** ISO 14229-1 server supporting services `0x10` (Session Control), `0x11` (ECU Reset), `0x14` (Clear DTCs), `0x19` (Read DTCs), `0x22` (Read DID), `0x27` (Security Access with 3-attempt lockout), `0x2E`, `0x31`, and `0x3E` (Tester Present).
* **Hardware bxCAN Driver:** Bare-metal driver configured at 500 kbps with dual 32-bit hardware identifier acceptance filters for deterministic zero-CPU frame filtering.
* **Verification Suite:** **15/15 Unity C unit tests** + **9/9 Python automated diagnostic client validation tests** passing in CI/CD.

### ⚙️ 2. [stm32-dsp-vibration-spectral-analyzer](https://github.com/sherifred-singh/stm32-dsp-vibration-spectral-analyzer)
> **Real-Time 1024-Point Real FFT & Ping-Pong DMA Edge DSP Engine on STM32F446RE Hardware FPU**
* **Continuous Acquisition:** 50 kHz accelerometer sampling triggered via `TIM2 TRGO` into `ADC1` with zero CPU overhead using `DMA2 Stream 0` double-buffering.
* **FPU Acceleration:** 1024-point Real FFT execution on ARM Cortex-M4 hardware floating-point unit in under 1.1 ms (consuming only 5.3% of the CPU budget).
* **Vibration Diagnostics:** Raised-cosine Hanning windowing, parabolic sub-bin peak interpolation, Total Harmonic Distortion (THD %) computation, and automated ISO 10816-3 industrial machinery severity evaluation.
* **Verification Suite:** **7/7 Unity C unit tests** + Python real-time spectral waterfall visualizer utility.

### 🛡️ 3. [stm32-failsafe-iap-bootloader](https://github.com/sherifred-singh/stm32-failsafe-iap-bootloader)
> **Brick-Proof Dual-Slot In-Application Programming (IAP) Bootloader on STM32F446RE (512 KB Flash)**
* **Flash Partitioning:** Asymmetric NOR Flash partitioning (Slot A: 192 KB, Slot B: 256 KB) strictly aligned to physical erase sector boundaries.
* **Integrity Engine:** Hardware CRC-32 accelerator (`0x04C11DB7`) over entire binary payload with structured 40-byte `image_header_t`.
* **Execution Handover:** Main Stack Pointer (MSP) sanity checking within physical SRAM bounds (`0x20000000`–`0x20020000`), vector table relocation (`SCB->VTOR`), and execution jump.
* **Rollback Protection:** Watchdog probation window (`SLOT_STATE_TESTING`) with automated rollback to the alternate golden slot if new firmware faults repeatedly.
* **Verification Suite:** **10/10 Unity C unit tests** + Python IAP packager and UART flasher tool.

### 🌐 4. [stm32-esp32-industrial-edge-controller](https://github.com/sherifred-singh/stm32-esp32-industrial-edge-controller)
> **Distributed Dual-MCU Industrial IoT Edge Controller & Gateway (STM32F446RE + ESP32-S3 FreeRTOS)**
* **Architectural Partitioning:** Real-time deterministic sensor acquisition and actuator safety on ARM Cortex-M4 (STM32F446RE @ 180 MHz), offloading wireless BLE 5.0 diagnostics and MQTT cloud telemetry to dual-core ESP32-S3.
* **Deterministic DMA Protocol:** Circular DMA UART with hardware IDLE line interrupt, fast 256-entry CRC-16-CCITT table verification, and compile-time struct static assertions.
* **Hardware E-Stop:** Sub-millisecond physical shutdown directly cutting `TIM1->BDTR` Main Output Enable (MOE), clearing PWM duty to 0%, and de-energizing relay coils.
* **Verification Suite:** **7/7 Native C99 unit tests** + **6/6 Python protocol stress tests** running in automated GitHub Actions CI.

### 🔋 5. [pytest-bms-diagnostic-framework](https://github.com/sherifred-singh/pytest-bms-diagnostic-framework)
